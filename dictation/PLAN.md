# 开发计划（2026-11-13）

目标：把「等级 / 进度 / 出题质量 / 话题 / 发音来源 / 预览流程」落成可验证的版本。
原则：每阶段可独立上线、可回滚；新逻辑优先做成纯函数 + 离线测试。

## P0 收尾（0.15.x，1 天）

- [ ] 预览页：播完后加 Skip → `POST /run/next`（换一句、不结束整轮）；出题移到预览页，加载中显示 `AI 正在出题中…`
- [ ] `/run/answer` 只返回复盘/得分，不再生成下一句
- [x] 发音改走宿主 DeepSeek TTS：`/audio` 返回官方 WAV，key 取自 `ctx.credentials`（与 LLM 同一份），失败回退系统语音（0.21.0）
- [x] 删掉 Piper 一键安装与非官方 Edge Read-Aloud（不再依赖 python3 / pip 镜像 / 模型下载 / 微软 token）
- [ ] 听觉验收：真机听 `stella` / `tide` 对单词题（`He`、`a`、`I`）的语种判定与清晰度
- [ ] 离线题库补逐词 `zh`（模型失败时提示不再空白）

验收：预览页可 Skip；loading 文案出现；`/audio` 返回 `audio/wav`（无 key 时 404、页面退回系统语音）；测试全绿。

## P1 难度与等级（0.16，2–3 天）

- [ ] `difficultyOf(item)`：词频（A1/A2/B1 表）+ 句长 + 从句数 + 语法点 → 分值 1–12（纯函数 + 测试）
- [ ] θ/σ 贝叶斯更新（含失误率 slip），每答一句更新；`P(B1) = 1 − Φ((d_B1 − θ)/σ)`
- [ ] 每题落 `band` / `difficulty`；档案 `bandStats`（分桶样本、正确率、弱项、最近批次）
- [ ] 升级门槛：P(B1) ≥ 0.9 且多维达标 → 报告页升级提示；迟滞（连续 3 批）
- [ ] Dashboard 等级卡：`A2 → B1 ████ 78%` + 「还差什么」清单 + 今日增量
- [ ] 自评卡（A2/B1/B2/C1/C2 + 能力描述）+ `bandSource: self|auto`

验收：固定作答序列 → θ/P(B1) 单调正确；进度条与清单随作答变化；升级只在达标时出现。

## P2 出题质量与话题（0.17，3–4 天）

- [ ] 提示词升级：等级词表、句长/从句约束、目标语法点、指定话题、2–3 条同难度示例
- [ ] 每句 3 候选 → 打分选优（等级贴合 / 生词数 / 弱项命中 / 自然度 / 相似度）
- [ ] 校验层：话题枚举、词表外词 ≤1、句长区间、语法点命中；失败重试/换题
- [ ] 话题表（24 个）+ 轮转（最少使用优先、最近 8 句去重）+ `profile.topics` + 首页话题覆盖
- [ ] `chunkZh`：每题一句自然中文（替代逐词拼接），host 校验与存档

验收：连续 30 句话题不重复相邻 8 句、每级句子难度落在区间；提示中文为整句而非词义拼接；候选打分有测试。

## P3 体验与打磨（0.18，2 天）

- [ ] 报告页一行进度提示（`A2 80% → 81%`）；里程碑（连续天数、弱项全绿）
- [ ] 7 天趋势小图（用档案数据）
- [ ] 系统 TTS 兜底优化（Premium/Enhanced 优先、逗号分句停顿）；无 key 时的提示文案
- [ ] 错误与降级文案统一（模型失败、语音不可用、网络错误）

## P4 可选 / 后续

- [ ] 升级小测（8–10 句混合）+ LLM 评卷（CEFR 描述符）
- [ ] 遗忘曲线与到期复习参与升级判断
- [ ] Windows WinRT 自然语音（Aria/Jenny）平台分支

## 每个版本固定动作

1. `node test/run.mjs` 全绿（新增逻辑必须有纯函数测试）
2. 版本号三处同步（package.json / lib/index.js BUILD / lib/client.js VERSION）
3. README/DESIGN 更新对应章节
4. 告知刷新与可验证点
