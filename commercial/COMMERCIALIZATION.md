# DSH「链接」面板 — 商业化探讨与评估

> **评估对象**：`references/`（包名 `dsh-links-panel`，MIT，工作区当前 v0.54.0）
> **评估时点**：2026-10-30（数据抓取 14:38–14:50 CST）。评估期间该插件被并行修改（0.53.6 → 0.54.0），本报告以**功能形态**而非具体版本号为准。
> **结论一句话**：**这不是一个"能不能卖"的问题，而是一个"没有收银台、没有分发、且功能正被大厂免费化"的问题——按现状直接收费的期望值为负；它真正的商业价值在别处（分发资产、作品集、以及"证据台账"这个更高价位的重定位）。**

| 问题 | 结论 | 信心 |
|---|---|---|

## 1. 先把产品看清：它到底是什么

### 1.1 事实核查（一手）

| 项 | 实测值 | 说明 |
|---|---|---|
| 形态 | DSH 右栏 tab（`links`），`keepMounted` 常驻 | 官方内置的右栏 tab 只有文件树 / 文档预览 / 终端 / 浏览器四种，**没有"链接/来源"这一类 —— 这是一个真空位** |
| 代码量 | client 4,010 行 + host 596 行；测试 753 行 | 单文件 lazy-CJS bundle，无构建步骤 |
| 测试 | `node test/run.mjs` **本次实跑通过** | VM + 假 React，不需要 DSH 在跑 —— 这是稀缺工程资产 |
| i18n | zh / en | 生态里多数同类插件只有中文 |
| 版本 | 工作区 0.54.0；**DESIGN.md 停在 v0.17.0** | 约 37 个版本没有回写文档，说明迭代速度 >> 文档速度 |
| 分发 | **npm 上 `dsh-links-panel` 返回 404**；仅通过 `file:` 链进本机 desktop profile | 当前**曝光 ≈ 0**，这是后面所有商业讨论的前提 |
| 数据面 | 纯本地：localStorage（探测缓存、忽略表、pin），无账号、无服务端、无遥测 | 隐私叙事成立，但也砍掉了"跨设备/团队"的商业化空间 |

### 1.2 它做了什么（能力边界）

- **一个对话级 URL 全景**：从 user/assistant 正文、`tool/call` 参数、`web_search` 的 `Sources:`、`web_fetch` 的 `Fetched` 首行抽取；归一化去重、追踪参数剥离、静态资源/API 端点/占位域名/内网地址/保留域名过滤。
- **可信度层**：Host 路由 `GET /dsh-links/meta` 抓页面 `<title>`/`<link rel=icon>`，只有 404/410/DNS/连接拒绝才隐藏（403、超时、非 HTML 保留）——这个"只隐藏可证明已死"的判定比多数同类工具更克制。
- **可用性层**：pin、搜索、排序、按根域名相邻、标签色点、`⋮` 菜单（右栏打开/系统浏览器/复制/定位回原文/忽略链接或整域）、忽略视图恢复、复制为 Markdown、手动改标题、重扫。
- **明确不做**：文件/图片、跨会话收藏库、星标、团队共享、AI 摘要、引用格式（BibTeX/APA）。

**一句话定性**：它不是一个"书签管理器"，而是一个**对话归档的出处索引器**——只是目前只做了"这一个对话"，且只做到"可读"，没做到"可举证"。

## 2. 平台事实：这条街没有收银台

### 2.1 DSH 的量级（一手 + 官方 API）

| 指标 | 数值 |
|---|---|
| 仓库 | `deepseek-ai/deepseek-harness`，MIT，创建 **2026-08-13** |
| Star / Fork | **266,162 / 32,272**（2.5 个月） |
| 本机版本 | **0.2.1-rc.3**；最新 release 当天为 **0.2.1-rc.5**，节奏约 3–7 天一个 alpha/rc |
| 内部包 | asar 内 308 个 `@deepseek-ai/*` 包、18,191 个文件 |
| 分发单位 | npm 包或 Git 仓库 → profile 的 `dependencies` + `dsh.profile.bundles` |
| 官方客户端包下载量 | `dsh-client-ui-*` 系列约 **1.4–2.7M/月**（npm）→ 用户基数大 |

### 2.2 "插件市场"的真实形态（对商业化最关键的一段）

一手探查 `app.asar` 内 `@deepseek-ai/dsh-plugin-market` / `-market-index` / `dsh-experimental-plugin-market-bundle`：

1. **没有官方市场**。`pluginMarket` 的 `indexes` 默认 `[]`，**默认不向任何市场发请求**；用户在 Plugins → Discover 里自己粘索引 URL。
2. **索引格式没有商业字段**。格式 1 只定义 name/version/description/author/keywords/category/labels/sortKeys/homepage/repository/icon/engines——**没有 price、license、purchase、entitlement**。
3. **不签名、不审核**。README 原文：索引内容"是市场的声明"，实际装什么由已安装 manifest 决定；安装只校验 `engines.dsh` 兼容性 + 构建脚本审批。
4. **官方在弱化"市场"**：0.2.2-alpha.2 把"自定义插件市场"改名为"自定义插件索引"。
5. **但不是没有分发**：社区侧已有 3 个以上目录型产品 —— `dshmarket`（30 天 758k 下载）、`dsh-plugin-catalog`（awesome-dsh-plugin.com，**7,723 条**）、`dsh.so`（宣称 **23,832 个**插件/工件，含 L1–L5 验证分级）、`dsh-m`。

> **含义**：DSH 给了"货架"，但**没给"收银台"**。任何收费都必须发生在站外（自建落页 + Lemon Squeezy/Polar 卖 key），且平台不背书、不分发、不结算、不负责退款。这是整个评估里最硬的结构性约束。

### 2.3 生态量级与需求分布（实测，30 天窗口 2026-09-30→10-29）

- npm 上带 `dsh-plugin` 关键词的包 **11,150 个**，带 `dsh` 的 **13,468 个**；目录型产品收录 **7,723 条**（npm 包与站点数字一致）。
- **下载分布极端长尾**：有下载数据的 3,969 个条目中，中位数 **1,162/30 天**；≥1 万仅 **127 个**；≥10 万 **16 个**；≥50 万 **2 个**。
- 品类条目数：ui **1,524**、tools 1,035、session 543、dev 465、workflow 429、model 409、usage 406、memory 333、theme 304 —— **UI 是最拥挤的赛道**。

**头部（30 天下载）**：billion-context（session）2,202,599 · dsh-market（市场）758,003 · 余额鲸鱼挂件（ui）316,890 · dsh-pet（fun）262,546 · dsh-context（usage）235,617 · **better-sidebar（ui）228,424** · cost-meter（usage）117,828。

**结论**：盘子很大，但**"大"集中在大工具/娱乐/市场这三类**；单点面板类插件的中位数就是一千多下载。**头部效应极强，长尾几乎没有商业价值。**

## 3. 竞争：它真正的位置

### 3.1 生态内直接邻居（实测 30 天下载）

| 插件 | 下载/30d | 与本产品的关系 |
|---|---|---|
| **dsh-chat-link-actions** | 9,330 | 对话里的链接/路径右键动作（含"引用回输入框"）——**功能重叠约 30%**，但它是通用动作层，不是清单 |
| **dsh-better-display** | 4,727 | 助手回答渲染**带编号引用角标 + 来源面板**（针对联网搜索）——**语义重叠最高**，形态不同（回答内 vs 侧栏） |
| dsh-knit | 3,800 | 把工作区文档按相关性列进侧栏——"侧栏清单"形态邻居 |
| dsh-quote-annotate-pro | ~2,835 | 划词批注 + 引用锚点，点回原文高亮——**"回到原文"能力重叠** |
| dsh-github-link | 1,238 | GitHub 链接悬停卡片 + 右栏浏览器打开 |
| dsh-cite-lens | 614 | PDF 引用跳转与 `/cite-links` |
| dsh-raindrop | 603 | Raindrop.io 只读看板（跨会话收藏的对照物） |
| **dsh-link-collect** | 无 npm 数据（★1） | **最像"跨会话版"**：链接存成 Markdown + 侧栏收藏夹 + 抓图标 + agent 工具 |
| **better-sidebar** | 228,424 | **不是竞品，是宿主**：提供侧栏 tab 注册服务，很多面板插件挂在它上面 |

### 3.2 差异化与壁垒

- **差异化是真的**：目前没找到第二个"把**当前对话**出现的 URL 做全景汇总 + 可达性判定 + 定位回原文"的插件。`better-display` 做的是**搜索结果的来源 chips**，`link-collect` 做的是**收藏库**，`chat-link-actions` 做的是**动作层**。
- **但壁垒几乎为零**：核心算法（URL 正则 + 归一化 + 域名分类 + title 抓取）是公开套路；真正的工程量在"细节打磨"（死链判定克制、缓存 TTL、串行探测、字体/图标回退），这类优势**领先窗口约 1–3 个月**，且平台方 50 行代码就能内置一个"引用来源"tab。
- **结论**：即便做到品类第一，天花板约等于 `chat-link-actions` 到 `better-display` 之间——**年累计安装 5 万以内、30 天下载 1–2 万是乐观上限**，离商业规模差一个数量级。

## 4. 市场：需求真实，但价格被三堵墙夹住

| 墙 | 事实 | 对本产品的后果 |
|---|---|---|
| **大厂内置化** | NotebookLM 免费层就有 Sources 面板 + 逐段内联引用；Perplexity 几乎每次回答带 sources；ChatGPT Atlas 平均 **3.7 源/答案**；Claude 引用文档段落 | "汇总 + 点回原文"已是**及格线功能**，用户的参照系是"已付的 $20 订阅里免费带的" |
| **价格地板 = $0** | Karakeep / Linkwarden 自托管全功能免费；Obsidian 本体免费；Raindrop 免费层无限书签 | 本产品 90% 的功能（去重、死链、图标、pin、标签）在竞品里都在免费层 |
| **价格天花板 = $20/月** | ChatGPT Plus / Claude Pro / Perplexity Pro 均 $20；Google AI Pro $19.99 | 用户不会为"整理来源"再开一份订阅 → 只能做低价 add-on 或买断 |

**单功能工具的定价中枢（官方定价页实测）**：Linkwarden Cloud $3/用户/月 · Karakeep Pro $4/月（$40/年）· Obsidian Sync $4/月 · mymind $4.99/月 · Readwise Reader $7.99/月 · Glasp/Recall $10+/月。**买断档**只有品牌/刚需产品能站住（Sublime Lifetime $400、EndNote $275），消费级收藏工具买断现实价 **< $50**。

**反例（近两年退场的同类产品）**：Omnivore（2024-11 被收购后关停）、Pocket（2025-07-08 关停）、Arc（2026-12-22 关停）。需求真实，**收钱困难**。

**用户结构错配（这是最扎心的一条）**：

| 人群 | 痛点强度 | 愿付 | 本产品匹配度 |
|---|---|---|---|
| AI 重度研究者/分析师 | 强 | $5–10/月 | 部分（单会话是硬伤） |
| 开发者/技术调研 | 强 | $0–5/月 | 部分（Markdown 出处清单命中） |
| 创作者/编辑/事实核查 | 强 | $10/月 | **较强** |
| **团队/合规/尽调** | 中 | **$3–10/席位/月（最有钱）** | **架构不支持**（无账号/无服务端/localStorage/单会话） |
| 本地优先/隐私原教旨 | 中 | 一次性 $25–50 或 $0 | **最强匹配，但最不肯付订阅** |

> **含义**：最愿意付钱的人，产品结构上服务不了；产品结构上最服务得了的人，最不愿意付订阅。**这是定位层面的矛盾，不是功能层面的缺口。**

## 5. 七条商业化路径，逐条打分

评分：5 分制。**收入上限**＝这条路的理论天花板；**成本**＝第一年投入（反向计分，5＝最便宜）；**可行性**＝今天就能动手的程度；**风险**＝反噬/法律/口碑风险（5＝最安全）。

| # | 路径 | 收入上限 | 成本 | 可行性 | 风险 | 一年期望值 | 结论 |
|---|---|---|---|---|---|---|---|
| A | **免费开源 + 赞助/打赏**（GitHub Sponsors 0%、爱发电 6%，或 `dsh-tip-jar` 模式） | 1 | 5 | 5 | 5 | **$0–500** | **推荐作为起点**：零承诺、零退款、零客服 |
| B | **一次性买断 license**（$19，含 12 个月更新；离线 Ed25519 key） | 3 | 3 | 4 | 3 | **$150–2,300 GMV** | 可做，但**只能卖"12 个月更新"**，绝不卖"永久" |
| C | **订阅 SaaS 化**（跨会话链接库 + 团队共享 + AI 归纳） | 4 | 1 | 2 | 2 | 需 300–500h + 后端，正面对撞 $3–4/月竞品 | **不建议**：放弃本地卖点、抢最卷的价位 |
| D | **增值服务/定制/咨询**（企业内插件、兼容性维护） | 3 | 3 | 3 | 4 | **$0–10k**（不可预测） | 可被动接受，不主动建业务 |
| E | **打包出售**（与 session/context 类插件做 bundle，$10–20） | 3 | 3 | 3 | 4 | $300–3,000 | 有生态先例（`@dfy-plugins/dsh-bundle` 42k/月），但需要产品组合 |
| F | **卖给平台/被官方内置**（当作退出） | 2 | 4 | 1 | 3 | ≈0（无先例、无收购方） | 不成立，但**内置风险要按"必然"来规划** |
| G | **不直接变现，转做分发与作品集资产** | 4 | 4 | 5 | 5 | **不可测但期望值最高** | **推荐作为主线**：用 7,723 个插件的红海换"可信的工程样本"，再转向高需求品类或接单 |

**组合推荐**：**A + G 为主线，B 作为"有人主动要买才开"的旁路，C/D/E 不主动做。**

理由：A 的边际成本几乎为零；G 的资产（DSH 客户端集成的深度经验 + 高完成度代码 + 测试体系）在一个人人都在发插件的生态里是稀缺的；B 在没有分发的前提下等于 0；C 会把产品的核心叙事（本地、无账号）拆掉。

## 6. 单位经济模型（把账算给你看）

### 6.1 关键假设（可替换）

| 假设 | 取值 | 依据 |
|---|---|---|
| 首年累计安装 | 悲观 4,000 / 基准 10,000 / 乐观 25,000（爆款 50,000） | 对应稳态 30 天下载 ≈ 400 / 2,000 / 5,000；插件无自动更新，下载 ≈ 新增安装 |
| 免费→付费转化 | 0.5% / 1.5% / 3% | 买断制开发者工具常规区间；隐私向用户偏下限 |
| 客单价 | **$19 一次性**（含 12 个月更新） | 单功能工具买断现实价 <$50；$9 以下被支付固定费吃掉 |
| 支付/税务摩擦 | 7.6%（Lemon Squeezy 5% + $0.50 于 $19） | 官方费率 |
| 年维护工时 | 150 h（AI 辅助）/ 300 h（不借助 AI） | DSH 每 3–7 天一个 rc 含破坏性变更；本插件 4,600 行 |
| 工时机会成本 | ¥150/h ≈ $21 | 中国开发者副业口径 |

### 6.2 先定位：多少下载才算"厉害"（实测分布，n=3,969）

| 30 天下载 | 在全生态的位置 | 对本产品的含义 |
|---|---|---|
| ≥500 | 前 89.3% | 发布 + 目录收录后的**基本盘** |
| ≥1,162（中位数） | 前 50% | "正常"水平 |
| ≥2,000 | **前 24.4%** | 基准目标 |
| ≥3,000 | 前 14.1% | 优秀；也足以证明真实需求 |
| ≥5,000 | 前 7.7% | 乐观上限（同级对照：`chat-link-actions` 9,330、`better-display` 4,727） |
| ≥10,000 | 前 3.2% | 品类第一 |

### 6.3 三情景（含一个"爆款"上限）

| | 累计安装 | 转化 | 付费单 | GMV | 净收入(扣 7.6%) | 维护成本 | **净收益** |
|---|---|---|---|---|---|---|---|
| 悲观（后 50%） | 4,000 | 0.5% | 20 | $380 | **$351** | $1,680（80h） | **−$1,329** |
| 基准（前 25%） | 10,000 | 1.5% | 150 | $2,850 | **$2,633** | $3,150 | **−$517** |
| 乐观（前 8%） | 25,000 | 3% | 750 | $14,250 | **$13,163** | $3,150 | **+$10,013** |
| 爆款（前 3%） | 50,000 | 3% | 1,500 | $28,500 | **$26,325** | $3,150 | **+$23,175** |

**盈亏平衡点**：需要 179 单。按乐观转化 1.5% → **约 12,000 累计安装**（稳态 30 天下载 ≈ 1,400，全生态**前 36%**）；按悲观转化 0.5% → 需 35,800 安装（前 5%）。

**换句话说**：**打平需要"处在生态前三分之一"和"转化率 1.5%"同时成立；想真正赚钱，得进前 8%。** 而"前 8%"意味着要和 `better-display`（4,727）、`chat-link-actions`（9,330）这种已经被目录推荐、有社区帖的插件抢同一批用户。

**敏感度**：定价 $29 且转化 1.5% → 平衡点降到约 7,800 安装；转化率跌到 0.8% → 升到约 22,400（前 7%）。**模型对转化率极度敏感，而转化率恰恰没有任何本地数据可估**——这是"拍脑袋定价"最容易翻车的地方。

### 6.4 两条对照

- **纯打赏情景**：收入 $0–500/年，维护降级为"坏了再修"（≤40h/年 ≈ $840）→ **净收益 −$840 ~ −$340**，且不承担退款、承诺、客服。**期望值略好于基准 license 情景。**
- **卖"永久 license"情景**：一次性收 $19 × N，但承诺无限期适配 → 第 2 年起维护成本照付、收入归零，**结构性负期望**。这是本报告最坚决的否决项。

## 7. 风险清单

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| **平台吸收同类功能**（官方加一个"引用/来源"tab） | 中–高 | 付费价值瞬间归零 | 只做"平台不愿意做的深度层"（审计/导出/跨会话）；永不为单点功能收永久费 |
| **版本钉死**（`engines.dsh: 0.2.1-rc.3`，周更破坏性变更） | 高（已在发生） | 每次升级都要适配；用户换版本插件即失效 | 声明"支持矩阵 + 尽力适配"，版本号策略改成 `dsh` 兼容区间 |
| **MIT + 明文 bundle 被 fork 转售** | 中 | license 锁 5 分钟可 patch | 承认 license 是"合规凭证"，不做技术锁；用品牌/官方发行版区分 |
| **无支付/无协议，合规自担** | 确定 | 税务、退款、客服全自付 | 用 MoR 平台（LS/Paddle）转移税务；退款政策前置写清 |
| **口碑风险**（收费一个开源单机插件） | 中 | 社区拉黑、目录下架 | 走 "Free + Optional payments" 路线；收费点必须是"新增的深度能力"而非既有功能 |
| **数据误导**（npm 下载≠用户） | 高 | 高估市场 2–5 倍 | 模型里明确"下载≈安装"，用目录月榜交叉验证 |
| **文档/版本脱节**（DESIGN 落后 37 个版本） | 确定 | 付费产品不可维护 | 上架前必须补 CHANGELOG + 兼容矩阵 + 支持政策 |

## 8. 如果一定要商业化：分阶段建议

### 阶段 0（本周，约 4–6 小时）：**先把曝光从 0 变成 1**
1. `npm publish`（当前 404；`files`/`exports`/`engines` 已具备发布条件）。
2. 提交 `awesome-dsh-plugin.com` 目录（7,723 条目的主流量入口）与 `dsh.so`；读 `dshmarket` 收录规则。
3. README 加"兼容性矩阵 + 已知限制 + 打赏入口"三节。
4. 补 DESIGN.md 到当前版本（付费产品不能有三周前的设计文档）。

> 没有这一步，后面所有路径的期望值都是 0。**这是唯一一件"确定正确"的事。**

### 阶段 1（30 天）：**用零承诺的方式测试真实付费意愿**
- 加打赏入口（GitHub Sponsors + 爱发电，或生态现成的 `dsh-tip-jar`）。
- 在 README/issue 模板里放一句："如果这个面板帮你省了时间，赞助我；如果需要团队/审计能力，告诉我你的场景。"
- **只观测，不谈价**。看三个数：30 天下载、Star 增速、**主动提出付费/团队需求的 issue 数**。

### 阶段 2（90 天，条件触发）：**重定位为"证据台账"再谈收费**
只有同时满足以下条件才启动：
- 30 天下载 ≥ 3,000（≈ 全生态前 14%）；
- 至少 3 个不同用户提出"跨会话/导出/审计/团队"诉求；
- 维护工时稳定在 ≤ 8 h/月。

**重定位方向（本地优先、与平台内置不冲突）**：`Evidence Ledger / 出处台账`
- 每条链接带：出现时间、来源构成（我发的/工具带回/回答引用）、可达性状态、标题/站点、手动备注、**快照或归档指针**；
- 一键导出：Markdown 引用附录 / CSV / JSON（供文档、PR、报告、尽调）；
- 跨会话索引（本地 SQLite/JSONL，不上云）；
- 可选：用 DSH 自身模型对"本次对话的出处集合"做一次归纳（复用用户已付的 API，不引入服务端）。

**定价**：$29 一次性（含 12 个月更新）；若出现团队诉求，再评估 $199/团队/年（含审计导出与支持）。**订阅制不做。**

### 阶段 3（12 个月）：**二选一**
- **若数据支持**：把"证据台账"做成独立产品（仍不上云优先），按年授权；同时保留免费社区版。
- **若数据不支持**：冻结收费尝试，把它定位为**作品集与生态入口**，把商业化精力转向生态里真实有量级的需求（session/context/memory，见 §2.3），或承接插件定制。

### Kill criteria（写死，避免自我欺骗）
- 发布 30 天后 npm 下载 < 800（低于生态 78% 的插件）→ 不做任何收费包装；
- 90 天后无 ≥3 条付费/团队诉求 → 永久放弃 license，只保留打赏；
- 任一版本适配成本 > 8 h/次 → 降低承诺（停止"尽力适配"话术），避免隐性负债。

## 9. 正反方观点（把话说全）

**Bear case（为什么它很可能永远收不到钱）**
1. 收银台不存在，分发靠社区目录，转化只能来自 README 的溢出流量；
2. 功能在竞品免费层里就有，平台自己两个月内补了 5 项社区能力，这个 tab 是"顺手做"的难度；
3. 平台周更 pre-release，任何收费承诺都会变成维护负债；MIT + 明文 bundle 让"卖 key"只是道德约束；
4. 最有钱的团队客户，产品结构上服务不了；最匹配的隐私用户，拒绝订阅。

**Bull case（什么情况下它值钱）**
1. **"证据台账"是平台不愿做也不擅长做的层**：大厂只给"点得回去"，不给"可导出的出处证据链"；研究/编辑/合规人群为这个愿意付 $29–99；
2. **DSH 生态是新的、空的、增长快的**（2.5 个月 26.6 万 star，7,723 个插件但几乎全是同类平庸品），**先发者可以靠"完成度"吃掉品类心智**——`better-sidebar`（22.8 万/月）就是靠"把侧栏做成平台"赢的；
3. **它是作品集**：在一个 1 万多人发插件的生态里，一个 4,600 行、有离线测试、中英双语、细节克制的插件，是**接单/求职/被官方注意**的最强凭证——这条路的期望值可能高于卖 license 两个数量级。

## 10. 附录

### 10.1 我实测的方法与口径

| 数据 | 方法 | 口径/局限 |
|---|---|---|
| DSH 平台事实 | Node 解析 `app.asar`（182MB 归档，非目录），读 header 后按 offset 提取 308 个 `@deepseek-ai/*` 包的 README/源码 | 只读；本机版本 0.2.1-rc.3，可能落后官方 rc.5 |
| 仓库数据 | GitHub API `/repos/deepseek-ai/deepseek-harness` | 2026-10-30 抓取 |
| 生态规模 | npm registry search（`keywords:dsh-plugin` / `dsh` / `deepseek-harness`）+ `dsh-plugin-catalog` 包内 `plugins.json`（7,723 条，含 30 天下载窗口） | npm 下载量含 CI/镜像，**≠ 用户数**；`dsh.so` 宣称 23,832（口径更宽，含 GitHub 与子包），两个数不可混用 |
| 竞品下载 | 目录 `downloads` 字段（窗口 2026-09-30→10-29），并与 npm API 交叉核对 | 同一插件可能有多个 npm 包名（如 better-display 有 3,720 与 4,727 两个） |
| 外部定价 | 官方定价页/帮助中心（访问 2026-10-30） | 见 `research/market.md` §7 的来源清单 |

### 10.2 数据缺口（别在对外材料里当事实引用）

1. **DSH 真实 MAU/DAU**：只有 star/fork 与 npm 下载，无官方活跃数据；
2. **单个插件的真实用户数**：npm 下载不能换算用户（更新/CI 会重复计数）；
3. **生态付费先例**：结论是"未发现"，不是"不存在"（7,723 条按描述关键词全查，未穷尽 GitHub 仓库）；
4. **Raindrop Pro 精确价**（前端渲染，未取到金额）、Dia/Cubox 定价；
5. **DSH 是否发布过插件商业条款**：未检索到；若存在"禁止商业插件"条款，站外收费路径直接关闭；
6. **团队/合规需求是否存在**：本报告只证明"架构不支持"，未证明"有人要"——这正是阶段 1 要验证的。
