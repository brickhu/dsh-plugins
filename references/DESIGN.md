# DSH「链接」面板 — 产品设计

> 状态：v0.17.0 已实现（2026-10-30）
> 工作名：链接（URL 收藏夹）／包名 `@local/dsh-links`
> 工程目录：本仓库 `references/`（宏仓库 `~/Projects/dsh-plugins`）

## 1. 要解决什么

AI 对话里经常出现大量有用 URL（官方文档、仓库、文章、视频），但它们散落在工具结果和回答正文里，翻历史找不回来。用户原话：

> "对话中涉及到很多有用的外部 URL，它们被埋藏在对话历史中，我希望能够以一个收藏夹列表 +（提及次数）的方式呈现。"

所以这个面板只做一件事：**把当前对话里出现过的所有 URL 汇总成一张可扫读、可跳转、带次数的清单。**

明确不做（避免功能重叠）：

| 不做 | 原因 |
|---|---|
| 文件 / 图片 / 附件 | 右栏「文件」tab 与 `deliverables` 已在负责 |
| 所有参考物混排 | v0 目标单一：URL |
| 跨会话收藏夹、星标 | 用户选择 v0「先只做本对话列表」 |
| 额外发请求抓页面标题 | 隐私 + 失败态；标题只从对话现有文本里取 |
| Host 端全量投影 | v0 用客户端已加载窗口，成本低；缺口用「加载更早」补齐 |

## 2. 标签（tag）而不是分类

每条链接带 **一组标签**，不是单一分类；同一个 URL 可以同时是「代码 + 工具」。标签既是
筛选维度，也在行尾用小色点显示。

| 标签 | 含义 | 典型 | 判定 |
|---|---|---|---|
| **资料** | 文章、博客、新闻、文档、论文、PDF | wikipedia、medium、`docs.*`、arxiv、`.pdf` | 默认标签；文档子域、文档站、阅读类扩展 |
| **代码** | 仓库、源码文件、技术问答 | github、gitlab、stackoverflow、`.py/.ts/.rs/...` | 代码托管与问答域名、代码扩展 |
| **工具** | 在线工具、包注册表、产品页 | npm、pypi、codepen、figma、vercel、notion | 工具类域名表 |
| **媒体** | 视频、播客、图片、设计稿 | youtube、bilibili、spotify、figma、`.mp4/.png` | 媒体域名表、媒体扩展 |

**多标签**：CodePen / CodeSandbox / Replit / JSFiddle / Observable / HuggingFace 同时是
「代码 + 工具」；Figma 是「工具 + 媒体」；`.ipynb` 是「资料 + 代码」；GitHub 仓库是「代码」；
`docs.github.com` 是「资料」。任何认不出的页面默认「资料」，每行至少一个标签。

「被引用」筛选已移除。

## 3. 计数与去重

- **次数 = 出现次数**（用户选择）。同一轮里搜索结果出现 3 次 + 回答引用 1 次 = ×4。
- **同一 URL 只保留一行**，行内用徽标显示来源构成：我发的 / 工具带回 / 回答引用。
- 归一化去重：忽略 `www.`、协议、尾斜杠、`#锚点`，去掉 `utm_*`、`fbclid`、`gclid`、`spm` 等追踪参数。
- 路径大小写保留（路径是大小写敏感的），host 统一小写。
- 排除 `localhost`、`127.x`、`10.x`、`192.168.x`、`172.16-31.x`、`*.local`、纯数字 host、`mailto:`/`file:`/`javascript:`。
- 排除**静态资源文件**（图片/图标/字体/样式）：`.png/.jpg/.jpeg/.gif/.webp/.avif/.bmp/.svg/.ico/.tif/.heic/.woff/.woff2/.ttf/.otf/.eot/.css/.map` 结尾的 URL 不当参考；`.mp4/.mp3` 这类媒体文件和 `.pdf` 文档仍保留。
- 只接受合法**主机名**：字母/数字/点/连字符，且最后一节须是像 TLD 的字母串（或 `xn--` 形式）。`https://x$`、`https://a.b`、`https://foo.1` 这类“一看就不是站点”的字符串直接丢弃。
- **不接受 IP 字面量**（v4 / v6，公网也排除）：IP 端点不是"网页参考"，`8.8.8.8`、`[2606:4700::1111]` 都不进列表。
- 排除 **API / fetch 端点**（它们是被调用的接口，不是给人读的页面）：`api.*` 主机；首段是 `api` / `graphql` / `rest` / `rpc` / `openapi` / `swagger` / `jsapi` / `fetch` 的路径；`/v2/` 这类版本化路径；`.json` / `.jsonl` / `.ndjson` 数据文件。`/docs/api` 这类讲 API 的文档页仍保留。
- **无法访问的链接不展示**：Host 探测每个页面，只在**可证明打不开**时移除——HTTP 404 / 410，或域名解析失败、连接被拒。403（反爬）、超时、5xx、非 HTML 内容（PDF 等）保持显示，因为浏览器里往往能打开。
- 系统黑名单（一处集中）：状态回显/请求捕获服务（`httpstat.us`、`httpbin.org`、`requestbin`、`beeceptor` 等）+ 本仓库测试夹具域名（`harness.dev`、`hello.dev`、`notexample.com`），原因码统一为 `blocklist`。
- 用户黑名单：行菜单「隐藏 xxx 整个域名」写入**全局域名黑名单**（`dsh-links.blocked-hosts.v1`），对所有会话生效；旧版本按会话存的域名条目会迁移进来。
- 排除**占位域名**：注册域名的第一段是 `acme` / `example` / `foo` / `bar` / `baz` / `qux` / `demo` / `sample` / `placeholder` / `dummy` / `test` 之一（`acme.dev`、`sub.acme.co.uk`、`foo.com` 都在内）。文档、测试夹具、示例代码里满地都是它们，真站点几乎不会用。
- 排除保留的文档/测试域名（RFC 2606 / 6761）：`example.com`、`example.net`、`example.org` 及其子域，
  以及 `.example`、`.test`、`.invalid`、`.localhost` 后缀。测试会话、粘贴的示例数据和文档示例都爱用这些
  名字，它们永远不是真参考。

## 4. 界面

右栏新增 tab 类型「链接」，从右栏顶部「+」的 guide 页打开；`keepMounted` 保留搜索 / 排序 / 忽略状态。

```
┌ 链接 · 18                          [次数优先] ┐
│ 🔍 搜标题、域名或路径                          │
│ (全部 18)(资料 9)(代码 6)(工具 4)(媒体 3)       │
├───────────────────────────────────────────────┤
│ [◧] DeepSeek - Wikipedia                ×3  ⋮ │
│ [◧] Harness (disambiguation)            ×1  ⋮ │
│ [◧] deepseek-ai/deepseek-harness        ×2  ⋮ │
│ [◧] Node.js — Run JavaScript Everywhere ×1  ⋮ │
│ [◧] Example Domain                      ×3  ⋮ │
└───────────────────────────────────────────────┘
仅统计已加载的历史        [已忽略 2] [复制] [加载更早]
```

**列表是平的，没有分节头**。同一个根域名的行相邻排列（同一站点的子域也归到一起），但不画「github.com · 2」这样的标题行；分类筛选（全部 / 资料 / 代码 / 工具 / 媒体）已去掉，列表不再按标签过滤。

**置顶区与全部区分离**：

```
[           搜索标题、域名或路径           ]
置顶链接(2)
[图标] YouTube 视频                    ×9  ⋮
[图标] X                               ×2  ⋮
全部链接(20)
[图标] YouTube 视频                    ×9  ⋮
[图标] X                               ×2  ⋮
…（全部链接始终包含置顶项）
```

行菜单里「固定到顶部」把链接放进「置顶链接(N)」区，同时它仍出现在下方「全部链接(N)」里；再点「取消固定」即从置顶区移除。pin 是全局的（跨会话），存 `localStorage`。

**行**：站点图标 + 标题（取不到标题时就是整条 URL）+ 标签色点 + `×N`（出现次数 > 1 时）+ `⋮` 菜单：

| 菜单项 | 行为 |
|---|---|
| 在右栏打开 | 用右栏浏览器 tab 打开（不离开 DSH） |
| 在系统浏览器打开 | `window.open` 交给系统浏览器 |
| 复制链接 | 复制 URL |
| 定位到对话原文 | 滚动回携带该 URL 的消息并短暂高亮 |
| 忽略这条链接 | 隐藏该行；底部提示条可「忽略整个域名」或「撤销」 |
| 忽略 example.org | 隐藏该根域名下的所有行（含子域） |

- **排列**：先按当前排序（次数 / 最近）排，再把同根域名的行聚成相邻区块；区块之间按各自第一条出现的先后排列。
- **根域名**：去掉 `www.` 后取后两段（内置常见多段后缀如 `co.uk`、`com.cn` 的少量表，判断错了只影响相邻顺序）。
- **图标**：站点自己的 `/favicon.ico`（`loading=lazy`、`referrerPolicy=no-referrer`），失败时退化为分类色字母块。
- **点击行**：在右栏浏览器 tab 打开；`Cmd/中键` → 系统浏览器；`Enter/Space` 同样可打开。
- **悬停**：tooltip 显示完整 URL + 来源构成 + 最近 5 次出现。
- **底部**：「已忽略 N」进入忽略视图逐条恢复；「复制」把当前筛选结果复制为 Markdown 引用清单（按行首标签分组）；「加载更早」翻页重扫。

### 4.1 标题与图标：每次打开都刷新

行标题以**页面自己的 `<title>` 为准**：

1. **页面 `<title>`**（Host 抓取，优先）；
2. ~~对话里捕获的标题兜底~~ 已去掉：对话标签只是片段（如 `视频`），不再当标题；
3. **URL 本身**。

**打不开的页面不进列表**，但只剔除"证明已死"的：Host 返回的 `reason` 是 `gone`（404/410）、`dns`（域名解析不到）、`refused`（连接被拒）、`blocked`（解析到非公网地址）时隐藏该行；`timeout`、`http-error`（403/5xx）、`unsupported`（非 HTML）只是本机读不到，行保留、标题回退。

**本地优先 + 打开时一次轻量刷新**（v0.12.0）：标题/图标/死因/时间戳是**全局**缓存（不按会话分），打开 tab 先用缓存渲染；仅在 tab **首次打开**时跑一轮轻量补全（最多 16 条、每批 4 条、批间 150ms、复用 Host 缓存），切回 tab 不重复抓取；底部「刷新标题」按钮可按需重抓（最多 20 条、绕过 Host 缓存）。探测是**严格线性**的：客户端一次只发一个 URL、请求之间间隔 120ms；Host 侧也只按 1 并发处理、单页 12s 超时。网站图标同样走一个串行队列（一次只加载一张），不会出现一屏几十个并发请求。

**URL 信息持久缓存**：每条 URL 的标题/图标/死因/时间戳写入 `localStorage`（`dsh-links.probes.v2`，上限 600 条），打开面板立即用缓存渲染。重新探测按需进行：没缓存的立即探测；失败（超时等）5 分钟后重试；已缓存的标题 24 小时后才后台刷新（每轮最多 12 条）；判死的 6 小时后重查。这样重复打开不会再整轮重抓，标题也不会因为一次网络抖动丢失。

**图标**优先用页面声明的 `<link rel="icon">` / `shortcut icon` / `apple-touch-icon`（Host 从 HTML 里解析并转成绝对地址），没有才回退到 `https://<host>/favicon.ico`，再失败退化为分类色字母块。

**每次打开 tab 都会刷新一次**：标签页由 `keepMounted` 常驻，用 `IntersectionObserver` 监听它重新可见；一可见就清空本轮请求记录、重新探测页面上所有行（标题缺失的优先），并给图标 URL 加一个 `?dsh=<epoch>` 缓存串以绕过浏览器缓存。刷新期间行保留上一次的标题/图标，列表不会闪回裸 URL；刷新返回空的字段不会覆盖已有标题。

探测预算分两档：**缺标题/图标（或此前判不可用）的行永远优先探测**（累计上限 200），已经完整的行才按"每次打开刷新 60 条"的背景预算处理；这样长列表里排在后面的坏链接也会被判定、不会一直挂着 URL。

Host 侧 `GET /dsh-links/meta?urls=[...]&refresh=1` 会绕过缓存重新抓取；若该路由不可用（Host 插件版本旧于客户端），面板顶部会显示一条提示并要求完全重启——**host 代码只在启动时加载，改完必须退出重开，Cmd+R 不够**。每轮最多 60 个 URL、每批 8 个并发，单页 20 秒超时；之前判定"打不开"的行也会静默重试（恢复就重新出现）。探测结果缓存：标题 24h、404 1h、未知 10min；客户端只把标题/图标记进 `localStorage`（不可达状态不持久化）。

### 4.2 隐私与成本

- 页面标题由本机 Host 抓取（`ctx.web` + 公开地址校验、无凭据、有字节/时长上限），不经第三方代理。
- 站点图标由渲染进程直接向该站点请求，带 `referrerPolicy=no-referrer`、懒加载；请求量受可见行数量限制。
- 两者都会暴露"本机看过这个域名"，与在右栏浏览器打开该链接同类。

## 5. 数据从哪来

浏览器半负责扫描与渲染；host 半只提供一件事——页面标题（浏览器不能跨域读 `<title>`）。

**Host 半（`lib/index.js`）**：注册 `GET /dsh-links/meta`，用 `ctx.web.fetch()` 取 HTML、解析
`<title>` 并解码实体；批量上限 12 条、单页 8 秒超时、内存缓存 500 条。它依赖 `web` 与
`webServer` 两个宿主服务（`inject`），缺少任一服务时插件不激活，而不是让 profile 失败。

**浏览器半（`lib/client.js`）**：

1. 通过 `ctx.sessions.binding(sessionId)` 拿到当前会话的 `eventSource`。
2. `useSyncExternalStore` 订阅事件窗口（`{entries, hasMore, revision}`），只在窗口变化时重算。
3. 按事件类型抽取：
   - `user/message` → 正文 text 块（区分围栏代码）
   - `assistant/message` → 正文 text 块（跳过 reasoning）
   - `tool/call` → 解析 JSON 参数后的字符串叶子（能拿到 `web_fetch` 的原始 URL）
   - `tool/result` → 工具名从 `data.message.toolCallId`（或 `data.message.source.callId`）反查 call 表；`web_search` 只取 `Sources:` 之后的结果列表；`web_fetch` 只取首行 `Fetched <最终URL>`，正文里的导航链接不算；其余工具扫描全文
4. 每个 `seq` 的抽取结果缓存，翻页/流式更新时不会重复解析大段工具结果。客户端的窗口条目类型是 `'event'`（另有客户端临时行 `'transient'`）；`tool/result` 只有在它的 call 已进入窗口（工具名已知）时才缓存，否则「加载更早」补进 call 后会留下按全文扫描的旧结果。
5. 标题三级回退与有预算的 Host 查询见 §4.1。

## 6. 已知边界

- **忽略表是本地状态**：存在 `localStorage`，换机器/清站点数据会丢；不写回会话。

- **只统计已加载窗口**：初始是最近一窗（≥50 条消息 / ≥2 轮），更早历史要点「加载更早」。面板底部会如实显示"仅统计已加载的历史"。
- **大工具结果中段会被压缩**（>8192 字符只留头尾）：链接通常落在头尾，影响小；真正全量需要 host 侧 session projection（v1 评估）。
- **不额外抓页面标题**：标题优先取 markdown 链接文字，其次 URL 末段，最后域名；所以裸链接看起来就是域名。
- **工具结果正文里的链接不计数**：抓回来的整页 markdown 可能含上百个导航链接，只收检索结果与最终地址，避免噪音。实测四个真实会话里 `web_fetch` 正文合计含 151 / 334 / 965 / 352 条 URL，修好后每个抓取页只贡献它自己的地址。
- **tab 标题在打开时固定**：不带实时计数（chip 宽度有限，也避免标题席位高频重渲染）。

## 7. 路线图

- **v0.1（已实现）**：右栏 tab、三类分组、次数、搜索/排序、打开、定位、加载更早
- **v0.2（已实现）**：
  - 一键复制为 Markdown 引用清单
  - 行级「忽略此链接」+ 整域忽略 + 忽略视图恢复（按会话持久化）
  - 「被引用」筛选（只看回答引用过的高置信度参考）
- **v1（成本约 ×2~3）**：
  - host 侧 projection 做全量历史/跨 compaction
  - 星标收藏 + 跨会话"我的链接库"
  - 与「答案分享站」导出打通
  - 忽略规则跨会话共享（域名黑名单）
