# 参考链接（Reference Links）

DeepSeek Harness 右栏的 **参考链接** 标签页：把当前对话里出现的所有链接集中起来，
不用再翻聊天记录就能找到、置顶、改名并重新打开它们。

> 🖥 English version: [README.md](README.md)

---

## 解决什么痛点

和 AI 聊久了，一个对话里会引用**几十条链接**——文档、GitHub 仓库、文章、论文、面板。
等你想再用其中某一条时，痛苦就来了：

- 😩 往回翻几百条消息，只为找“刚才那个链接”；
- 🔁 同一个 URL 在好几轮里出现，分不清哪次引用才是你要的那次；
- 📋 只好先把链接复制到临时笔记里，最后还是很乱；
- 🧠 你记得的是“这条链接为什么重要”，而不是 URL 长什么样；

参考链接把这些聊天历史变成一份干净、可搜索的清单：全部集中在一个地方、重要的置顶、
“这条是在第几轮看到的？”一键跳回——不用再翻聊天记录。

## 能做什么

- **一个地方看全部链接**：你发的消息、助手回复、联网搜索和抓取的网页里的 URL；
- **置顶分组**：重要链接固定在顶部；
- **轮次统计**：每条链接显示出现在多少轮对话里，点数字可查看具体轮次并跳回原文；
- **搜索**：按标题或域名；
- **过滤**：「全部链接」标题前的漏斗图标可按对话轮次或 Host 过滤，标题会显示当前过滤项；
- **改名 / 隐藏**：给链接起自己的标题，或隐藏单条链接 / 整个站点；
- **真实图标**：优先显示站点自己的图标（站点提供日/夜两套时按主题显示）；
- **实时更新**：对话进行中自动追加，标签页关着也会继续收集；
- **快捷键**：macOS `⌘⇧L`，Windows/Linux `Ctrl+Shift+L`。

## 安装

### 在 DSH 里安装

1. 打开 DSH → 右侧栏 → **Plugins**；
2. 点 **Add plugin**，输入：

   ```
   dsh-links-panel
   ```

3. 安装并确认 bundle 已启用，然后**完全退出 DSH**（`Cmd+Q`）再启动；
4. 打开一个会话，展开右侧栏，点 **+** → **参考链接**。

### 命令行安装

```bash
npx --yes --package dsh-links-panel dsh-links-update
```

执行后同样需要完全退出并重启 DSH（更新也用它）。

## 使用

| 操作 | 方法 |
|---|---|
| 打开链接 | 点行（内置浏览器）；`⌘`/`Ctrl`+点击走系统浏览器 |
| 行菜单 | 行尾 `⋮`：复制链接、打开、修改标题、隐藏链接、批量隐藏站点、置顶 |
| 置顶 | `⋮` → **置顶这个链接**，置顶项显示在顶部 |
| 改名 | `⋮` → **修改标题…**，留空则恢复自动标题 |
| 隐藏 | `⋮` → **隐藏这个链接** / **批量隐藏 `<站点>`** |
| 恢复 | 底部「已隐藏」分组里 `⋮` → **恢复这个链接** |
| 过滤 | 点「全部链接」标题前的漏斗图标，选轮次或 Host；选「全部链接」清除 |
| 折叠分组 | 点分组标题（置顶链接 / 全部链接 / 已隐藏） |
| 跳到旧轮次 | 点行尾轮次数字，在弹窗里点某一轮即可跳转 |

底部显示已收录链接数、一个重新扫描按钮，以及当前运行版本。

## 更新

远端有新版本时，footer 版本号后会出现绿色 **↑**。点它可以看到更新命令，或直接执行：

```bash
npx --yes --package dsh-links-panel dsh-links-update
```

然后完全退出 DSH 再打开。仅刷新页面不够。

## 说明

- **标题来自对话本身**：链接文字、搜索结果标题、抓取到的页面标题，或你自己改的名字；
  都没有就显示 URL。插件不会主动抓页面标题，也不调用模型。
- **图标**在本地缓存；插件只在必要时逐个 host 请求站点图标。
- **数据都在本机**（浏览器 local storage）：置顶、自定义标题、隐藏列表和图标；
  重装插件不会丢失。
- **卸载**：DSH → Plugins 里移除 bundle，然后重启。

## 常见问题

| 现象 | 处理 |
|---|---|
| 看不到标签页 | 确认 bundle 已安装并**启用**，然后完全退出、重开 DSH |
| 版本号没变化 | 仅刷新页面无效，需要完全退出 DSH |
| 某站点没有图标 | 部分站点拒绝非浏览器请求，会退回自动生成的图标 |
| 一直有新版本提示 | 执行上面的更新命令后重启 DSH |

仍有问题请到 <https://github.com/brickhu/dsh-plugins/issues> 反馈，并附上 footer 里的版本号。
